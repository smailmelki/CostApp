## 📖 نبذة عن المشروع

**CostApp** هو تطبيق لإدارة مصاريف المشاريع، مطوّر باستخدام **C# و.NET MAUI**. يتيح لك إنشاء عدة مشاريع، وتحديد ميزانية لكل مشروع عند الحاجة، وتنظيم المصاريف ضمن تصنيفات، ثم متابعة إجمالي الإنفاق والمتبقي من الميزانية.

التطبيق مصمم بواجهة عربية واتجاه **RTL**، ويستخدم **الدينار الجزائري (دج)** كعملة افتراضية. تُحفظ البيانات في قاعدة SQLite محلية على الجهاز، لذلك يمكن استخدام الوظائف الأساسية دون اتصال بالإنترنت، ولا يعتمد التطبيق على حساب أو خدمة سحابية.

## ✨ المميزات

- **إدارة عدة مشاريع:** إنشاء المشاريع وتعديلها وحذفها، مع وصف وميزانية اختيارية.
- **ملخص لكل مشروع:** عرض إجمالي المصروفات وعدد السجلات والمتبقي من الميزانية.
- **تصنيفات المصاريف:** تنظيم المصروفات ضمن تصنيفات خاصة بكل مشروع.
- **إدارة المصروفات:** إضافة المصروف وتعديله وحذفه، مع المبلغ والتاريخ والملاحظة.
- **بحث سريع:** البحث في أسماء التصنيفات والملاحظات والمبالغ.
- **فلترة متقدمة:** تحديد فترة زمنية وتصنيف ونص بحث، مع إظهار عدد النتائج ومجموعها.
- **إدخال مبالغ عربي:** دعم الأرقام العربية-الهندية وصيغ الفواصل العشرية المختلفة.
- **نسخ احتياطي واستعادة:** تصدير قاعدة البيانات واستعادة نسخة سابقة مع فحوصات حماية.
- **الوضع الداكن والفاتح:** تغيير مظهر التطبيق من القائمة الجانبية.
- **استخدام دون إنترنت:** تخزين محلي للبيانات دون الحاجة إلى اتصال دائم.

```
    ├── SqliteBackupManager.cs     # النسخ الاحتياطي والاستعادة
    ├── SchemaComparer.cs          # مقارنة مخطط قاعدة البيانات
    ├── DialogService.cs           # رسائل وحوارات موحدة

    │   ├── DBContext.cs           # إعداد EF Core وترحيل البيانات

    │   ├── TreeItem.cs             # نموذج التصنيف
    │   └── DetailItem.cs           # نموذج المصروف
    ├── Platforms/                  # إعدادات المنصات
    └── Resources/                  # الصور والخطوط والأنماط
```

## 🗃️ قاعدة البيانات

تُحفظ قاعدة البيانات باسم **`CostAppDB.db`** في مجلد بيانات التطبيق الخاص بكل منصة.

يتضمن نموذج البيانات الأساسي:

| الجدول | وظيفته |
|---|---|
| `Projects` | بيانات المشاريع وميزانياتها |
| `TreeItem` | تصنيفات المصاريف المرتبطة بالمشروع |
| `DetailItem` | سجلات المصروفات وتواريخها وملاحظاتها |

يهيئ التطبيق قاعدة البيانات عند بدء التشغيل، ويتضمن منطقًا للتعامل مع بنية الإصدارات السابقة وربط البيانات القديمة بالمشروع الافتراضي عند الترقية. كما تُنفّذ عمليات الحذف المرتبطة ضمن معاملات لضمان اتساق البيانات.

## 💾 النسخ الاحتياطي والاستعادة

من شاشة التطبيق، يمكنك إنشاء نسخة احتياطية أو استعادة نسخة محفوظة.

### التصدير
- إنشاء نسخة باستخدام آلية SQLite Backup API.
- حفظ الملف بصيغة `.db` في المكان الذي تختاره.
- التحقق من وجود قاعدة البيانات قبل بدء التصدير.

### الاستعادة
تتضمن عملية الاستعادة إجراءات حماية، منها:
1. فحص سلامة قاعدة البيانات باستخدام `PRAGMA integrity_check`.
2. التحقق من الجداول والأعمدة المطلوبة.
3. إنشاء نسخة أمان من قاعدة البيانات الحالية قبل الاستبدال.
4. محاولة استعادة البيانات وترحيل المخطط عند الحاجة.
5. الرجوع إلى نسخة الأمان عند حدوث فشل أثناء العملية.

**نصيحة:** احتفظ بنسخة احتياطية خارج الهاتف، ولا تعتمد على النسخة الموجودة في الجهاز وحدها.

## 🚀 البدء والتشغيل

### المتطلبات

- .NET 10 SDK.
- حزمة عمل .NET MAUI المناسبة للمنصة.
- Android SDK ومحاكي أو هاتف Android لتشغيل نسخة Android.
- Visual Studio أو VS Code مع أدوات .NET المناسبة.
- جهاز macOS وXcode لبناء نسختي iOS وMac Catalyst.

### استنساخ المستودع

```bash
git clone https://github.com/smailmelki/CostApp.git
cd CostApp
dotnet workload install maui
dotnet restore CostApp.sln
```

### التشغيل على Windows

```powershell
dotnet build .\CostApp\CostApp.csproj -f net10.0-windows10.0.19041.0 -t:Run
```

### التشغيل على Android

```powershell
dotnet build .\CostApp\CostApp.csproj -f net10.0-android -t:Run
```

### البناء على macOS

لـ Mac Catalyst:

```bash
dotnet build CostApp/CostApp.csproj -f net10.0-maccatalyst
```

ولـ iOS:

```bash
dotnet build CostApp/CostApp.csproj -f net10.0-ios
```

يمكنك أيضًا فتح `CostApp.sln` في بيئة التطوير واختيار إطار الاستهداف المطلوب.
